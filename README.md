# SUPER DIAMOND NO HAND

使用 **ChatGPT 開發**的 Google Play Diamond Valley 台灣版自動遊玩擴充套件，支援 Edge 與 Chrome（Manifest V3）。目前版本 **0.4.5**。

## 風險與實測狀態

**使用風險自行承擔，包括但不限於被官方停權、查封、限制帳號或失去活動資格。** 本專案與 Google／遊戲官方無關，不保證相容性、獎勵、不中斷或不被偵測。

釣魚與採礦已觀察到物品與等級增加、任務交貨；打怪已成功結算，但仍可能被群怪或牆角困住而死亡。Boss 自動進場／等級門檻／連敗返回任務、寶庫與 Chrome 實機行為仍待驗證。台灣版官方停用解謎。本套件不操作抽獎或兌換 Play Points，也不提供繞過偵測功能。

## 下載與安裝

- [Edge ZIP](SUPER-DIAMOND-NO-HAND-edge-0.4.5.zip)
- [Chrome ZIP](SUPER-DIAMOND-NO-HAND-chrome-0.4.5.zip)

這是供使用者自行載入的未封裝來源 ZIP，**並非瀏覽器商店上架或已簽章 CRX**。GitHub ZIP 頁面按下載圖示或 Download raw file，再解壓縮到固定資料夾。

### Edge

1. 開啟 `edge://extensions`。
2. 啟用「開發人員模式」。
3. 按「載入解壓縮」，選擇解壓縮後包含 `manifest.json` 的資料夾。
4. 停用舊版 Diamond Valley 套件，避免重複執行。
5. 在 Edge 開啟 [台灣版遊戲](https://diamondvalley.withgoogle.com/intl/ALL_tw/game/)，登入並完成對應玩法教學。
6. 重新整理遊戲，確認左下角顯示「自動遊玩 0.4.5」。

### Chrome

同上，但步驟 1 使用 `chrome://extensions`，並載入 Chrome ZIP 的解壓縮資料夾。Edge／Chrome 分別儲存設定。

## 使用方法

1. 保持遊戲分頁可見，等待地圖載入。
2. 下拉選擇釣魚、挖礦、打怪或隨機輪替；Boss／寶庫為開發測試模式。
3. 展開「自動遊玩設定」，調整交貨倍數與 Boss 規則。
4. 按「開始自動遊玩」。正常操作、物品不足、短暫目標消失或斷線會等待或重試；按「停止」或 Esc 結束。
5. 面板顯示等級、鑽石、目前模式總物品與藍／紅／綠／黃各類數量。

### 交貨倍數

預設 4，範圍 1～100，可輸入小數。遊戲提供下一個任務的需求量，四種物資共用該需求量。

例如任務需求 10、倍數 4，**四種各自都必須大於 40**（至少 41）才回城交貨；不是四種合計 41。改為 2.5，四種各至少 26 才觸發。

啟動交貨批次後，連續交可完成的任務直到物資不足，再返回採集。未知任務需求不自行猜測。背包已滿但任一種類未達門檻時會等待；可降低倍數或停止後手動處理。每日任務／活動限制仍由遊戲決定。

### 幾等打王、失敗幾次返回任務

- 勾選「達到等級自動打王」才啟用自動挑戰，預設未勾選。
- 「打王等級」預設 40，代表**整體角色等級**。
- 「連敗」預設 3，可設 1～20 次。
- 在城鎮且沒有交貨批次時，達到門檻會尋找已解鎖 Boss 入口並進場；需要完成對應劇情與解鎖。
- 連敗達上限後返回先前任務模式；完成一批交貨後才再次挑戰。成功後返回任務，角色再升級才重新挑戰。
- 手動選擇 Boss 也使用連敗上限；挑戰結束後返回先前採集模式。
- 設定會即時儲存。連敗計數為目前頁面狀態，重新整理後重置。

**Boss 規則通過邏輯測試，尚未完成實機驗證；未解鎖入口、需手動選項或獎勵視窗時可能等待。** 不會替使用者選擇抽獎／兌換選項。

## 更新及故障處理

更新檔案後，先在擴充功能頁按「重新載入」，再重新整理遊戲。出現 `Extension context invalidated` 通常是舊頁面仍使用更新前的連接，重新整理遊戲。

分頁在背景時暫停操作；回到遊戲後恢復。離線等待連線，持續遊戲斷線會嘗試重新載入，具有頻率上限。需登入時由使用者自行登入。

牆角／群怪避讓仍在調整。若連續死亡可切換釣魚或採礦；如果官方更新遊戲檔案，程式可能需要相容性修正。提供回報時可附上版本、模式、面板狀態與錯誤文字。

## 50 等 VIP 釣魚

釣魚模式（含隨機輪替的釣魚回合）在角色整體等級達到 50，後自動尋路到船隻管理員，由官方流程判斷登船資格、繼續登船對話，進入 VIP 釣魚區。每次交貨返回後會重新登船。正在釣魚時先完成本輪，交貨優先；沒有船票或入口不可用時繼續一般釣魚。不修改資格或獎勵。新增登船流程已通過邏輯測試，實機仍待驗證。

## Boss 修正（0.4.5）

自動處理開場「立即遊玩」。釣魚及伺服器提交階段停止追擊；勝敗回報後等結果畫面再返回任務，失敗未達連敗上限則按重試。首次勝利不依賴隱藏的結果按鈕，不自動打開獎勵／抽獎頁。新增邏輯測試通過，完整實戰仍待驗證。

## 當日上限自動切換（0.4.5）

目前模式的交貨畫面顯示當日上限時，自動切換至尚未碰到上限、已完成教學的釣魚／挖礦／打怪模式，手動選擇模式也適用。順序為釣魚、挖礦、打怪，跳過目前模式與已達上限模式。全數遇到上限後保持啟用但暫停動作，每分鐘在線且分頁可見時刷新官方角色資料；每日交貨計數降低後自動恢復。官方交貨上限是共用的，切換模式不會增加交貨額度。已達上限紀錄保存在目前頁面，重新整理後重新判斷。停止／Esc 仍立即停止。

## VIP 登船修正（0.4.5）

50 等後先尋找船隻管理員，船票資料尚未同步不再阻止前往；不修改或繞過官方船票檢查。登船對話在角色失去碰撞接觸時仍可繼續。面板診斷增加 eligible、hasPass、inside、boat，以確認資格、登船結果與 NPC。實機仍需重新載入後驗證。
